# Student Lifestyle Analytics Dashboard

## Project Overview
This project analyzes student lifestyle habits and their impact on academic performance using Python and Power BI. The dataset includes information related to study hours, sleep patterns, stress levels, physical activity, social activities, and GPA.

The project focuses on identifying patterns and relationships between lifestyle factors and academic performance through data analysis, visualizations, and dashboard creation.

---

## Objectives
- Analyze student lifestyle behavior
- Identify factors affecting GPA
- Visualize relationships between study habits and academic performance
- Build an interactive dashboard using Power BI
- Generate meaningful insights from the dataset

---

## Tools & Technologies Used
- Python

- Seaborn
- Jupyter Notebook
- Power BI

---

## Visualizations Created
- Study Hours Distribution
- Study Hours vs GPA Scatter Plot
- Sleep Hours Analysis
- Stress Level Distribution
- GPA by Stress Level

---

## Key Insights
- Students who study more hours generally tend to achieve better GPA.
- Balanced sleep patterns may improve academic performance.
- High stress levels can negatively affect GPA.
- Social activities should be balanced with study schedules.
- Physical activity also contributes to maintaining a healthy student lifestyle.
